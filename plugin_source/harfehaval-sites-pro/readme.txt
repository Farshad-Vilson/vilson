نمایش حرفه‌ای و کاملاً راست‌چین نمونه‌سایت‌ها و نمونه‌کارها با مودال پیش‌نمایش زنده، فیلتر هوشمند، اسلایدشو، مقایسه، امتیازدهی و ویجت کامل المنتور.

== Description ==

**سایت‌های حرف اول Pro** یک افزونه‌ی فارسی و راست‌چین برای نمایش حرفه‌ای نمونه‌سایت‌ها، نمونه‌کارها و محصولات قالب است. مخصوص طراحان سایت، آژانس‌های دیجیتال و فروشندگان قالب طراحی شده تا نمونه‌کارها را به شکلی جذاب و فروش‌محور به مشتری نشان دهند.

= مهم‌ترین قابلیت‌ها =

* **مودال پیش‌نمایش زنده** — نمایش سایت واقعی داخل قاب با حالت دسکتاپ / تبلت / موبایل
* **فیلتر و جستجوی هوشمند** — بر اساس دسته‌بندی، ویژگی، وضعیت و مرتب‌سازی، بدون رفرش صفحه
* **حالت اسلایدشو (کاروسل)** — پخش خودکار، فلش، نقطه‌های صفحه‌بندی و ۱ تا ۶ کارت در هر نما
* **مقایسه‌ی محصولات** — مقایسه‌ی هم‌زمان تا ۳ نمونه در یک جدول
* **امتیازدهی ستاره‌ای و شمارنده‌ی بازدید** — تعامل واقعی کاربر با ثبت در سرور
* **علاقه‌مندی و پین کردن** — ذخیره‌ی محلی برای هر بازدیدکننده
* **تور راهنمای تعاملی** — آموزش گام‌به‌گام پیش‌نمایش برای کاربران تازه‌وارد
* **دکمه‌ی سفارش واتساپ** — تبدیل بازدیدکننده به مشتری با یک کلیک
* **کد QR دمو** — اسکن و باز شدن دمو روی موبایل
* **قالب‌های مشابه** — پیشنهاد هوشمند نمونه‌های مرتبط
* **ویجت کامل المنتور** — بیش از ۵۰ تنظیم بصری بدون نیاز به کدنویسی
* **ایزولاسیون کامل استایل** — بدون تداخل با قالب سایت شما
* **بهینه و سریع** — بارگذاری تنبل تصاویر، کش داخلی و REST API اختصاصی

= مناسب چه کسانی است؟ =

* طراحان و توسعه‌دهندگان سایت برای نمایش نمونه‌کار
* فروشندگان قالب و محصولات دیجیتال
* آژانس‌های تبلیغاتی و دیجیتال مارکتینگ
* هر کسب‌وکاری که می‌خواهد نمونه‌کارهای خود را حرفه‌ای ارائه دهد

== Installation ==

1. فایل زیپ افزونه را از مسیر **افزونه‌ها ← افزودن ← بارگذاری افزونه** آپلود کنید.
2. افزونه را **فعال** کنید.
3. از منوی **نمونه‌سایت‌ها** نمونه‌های خود را اضافه کنید (نام، دسته، تصویر، لینک دمو و ...).
4. ویجت **«سایت‌های حرف اول»** را در صفحه‌ساز المنتور قرار دهید و تنظیمات را دلخواه تغییر دهید.

== Frequently Asked Questions ==

= آیا به المنتور نیاز دارم؟ =
ویجت بصری روی المنتور کار می‌کند، اما افزونه شورت‌کد هم دارد و بدون المنتور هم قابل استفاده است.

= آیا با قالب من تداخل دارد؟ =
خیر. استایل‌ها به‌صورت کاملاً ایزوله بر اساس شناسه‌ی هر نمونه بارگذاری می‌شوند و با قالب سایت تداخل نمی‌کنند.

= آیا راست‌چین است؟ =
بله، افزونه به‌صورت بومی فارسی و راست‌چین (RTL) طراحی شده است.
